# 埋め込みの場所ごとの色と首都の点

`colors="JP:#2f6b4f,GB:#8a3b3b"`で、地域コードまたはISOコードごとに色を指定します。指定のない場所は配色の色を使います。`rgb()`や`hsl()`の中のカンマ、CSSの色名、`var(--name)`も使えます。不正な色は受け付けません。属性を指定すると、ホストの`options.colors`より属性が優先されます。

地図と場所の表示では、初期値で首都の点を表示します。`capital="off"`、`false`、`no`、`0`で点を非表示にします。`features="all"`でも点は表示しません。`capital="on"`では、選んだ水域などと一緒に首都の点を表示します。`capital`プロパティは真偽値で、属性にも反映されます。

通常の`drawChizu`と`mountChizu`の初期値、クイズの問題の選び方は変わりません。クイズでも場所ごとの色を指定できます。埋め込みビルダーのコードとリンクには色と首都の点の設定が含まれます。
