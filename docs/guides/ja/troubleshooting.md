## データや結果がない場合

| 結果 | 意味と確認すること |
| --- | --- |
| `loadCountry` / `loadDivisions` が `null` | そのコードの標準データがありません。対応するコード一覧を確認します。 |
| `loadFeatures` が `null` | その地図 ID の地物レイヤーがありません。地図本体は使えます。 |
| `countryByCode` が `undefined` | 国名の一覧にコードがありません。 |
| `focusRegionFit` / `regionCentre` が `null` | コードが null、またはその地図にありません。 |
| `insetFor` が `null` | 別枠がありません。通常は元の位置に描かれます。 |
| `wrapIntoBox` が `null` | 表示範囲内に、その点の横方向の複製がありません。 |
| `landAnchor` / `mainlandBounds` が `null` | 対象の輪郭がありません。 |
| `findQuestion` が `null` | 正解の地域が不明、または名前のない地域です。 |
| `projectPoint` / `unprojectPoint` が `null` | その投影は、この関数で変換できません。 |
| `readMapData` / `readMapColors` が `null` | 入力がない、または読み取りの条件に合いません。 |

## 地域や地物が表示されない

コードがどのキャンバスに属するかを確認します。世界地図の日本は `JP`、都道府県地図の東京は `13` です。地物レイヤーの地図 ID も一致させます。異なる地図のレイヤーを自動で再投影する処理はありません。名前は用意された元のデータに従います。日本語の読みがないことは、読み込みの失敗ではありません。

## ブラウザーでの準備と後始末

要素はブラウザーで作り、非同期のデータを読み込んでから結果を参照します。標準の読み込み・エラーイベントを扱います。モジュールの表示先には実際の HTMLElement を使い、取り除くときは `destroy()` を呼びます。未対応のコードは `null` ですが、データの import 自体が失敗したときは例外になります。画像にはスタイルを含めるか、記載された外部スタイルを指定します。
