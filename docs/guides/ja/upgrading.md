## 1.x の中で更新する

今回のドキュメント追加は、1.4.0 の SDK の動作とデータを保ちます。国・行政区画・地物の名前付きエクスポートは、既存のワイルドカードのパスを明示したものです。地図 ID、地域コード、形、投影、表示の初期値、シードの動作は変えません。`api.html` の既存のアンカーも残し、引数・戻り値・確認した例を新しいページに加えます。

保存した教材で形や解答順を保つ場合は、URL の版を固定します。データや SDK の版を変える前に[変更履歴](../../../CHANGELOG.md)を読み、別枠、世界地図の継ぎ目、地物レイヤー、クイズを確認します。

## 既存の SVG 表示から移す

固定の地図データと `drawChizu` から始めます。数値データと地域コードの対応は、ページ側で明確にします。移動、拡大、キーボード選択が必要なら `mountChizu` を加えます。経度・緯度の印は `projectPoint` で変換します。地図内の座標や別の投影には、その座標に合う変換が必要です。生成した SVG のパスは、経度・緯度の GeoJSON ではありません。

## 標準の埋め込みを更新する

表示形式、地域、シード、版を保ちます。ビルダーに追加した色と首都の設定も使えます。[埋め込みガイド](../../embeds.md)に、属性、コールバック、フレームのメッセージを記載しています。新しい言語の文章は、データや形の更新とは別に確認してください。
